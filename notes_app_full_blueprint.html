Auth flow — step by step
1
User "Login with GitHub" click kare
Tumhare Vercel app se GitHub OAuth page pe redirect
2
GitHub permission maange
Scope: repo (private repos read/write). User allow kare.
3
Access token mile — browser mein store
localStorage mein secure rakhna. Kisi ko nahi dikhta.
4
App automatically ek "noteflow-data" repo banaye
Pehli baar login pe GitHub API se private repo create karo
5
Ab saari notes us repo mein save hongi
GitHub API calls token ke saath — user ko kuch dikhta nahi
