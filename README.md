# 📝 NoteStream – Modern Notes App

Welcome to **NoteStream**, a sleek and high-performance note-taking application built with the latest web technologies. This project is crafted with precision to provide a seamless user experience.

> **Developed by:** [Coderafroj](https://github.com/coderafroj)

---

## 🚀 Key Features

* **Fast & Snappy:** Built on Next.js 15 for server-side rendering and speed.
* **Modern UI:** A beautiful, minimalist interface focused on readability.
* **Responsive:** Works perfectly on Desktop, Tablet, and Mobile.
* **Geist Typography:** Optimized for a premium developer-tool feel.
* **CRUD Ready:** Create, Read, Update, and Delete notes effortlessly.

## 🛠️ Tech Stack

| Tool | Purpose |
| :--- | :--- |
| **Next.js** | React Framework (App Router) |
| **TypeScript** | Type-safe development |
| **Tailwind CSS** | Styling & Layout |
| **Geist Font** | Professional Typography |
